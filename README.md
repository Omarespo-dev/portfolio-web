
# 🌐 Portfolio Personale

Questo progetto è un **portfolio web responsive** sviluppato per presentare le mie competenze, i miei progetti e le modalità per contattarmi.
Il sito è stato realizzato con un design moderno, animazioni leggere e componenti modulari, pensati per garantire mantenibilità e scalabilità del codice.

---

## 🚀 Tecnologie Utilizzate

* **React.js**
* **JavaScript (ES6+)**
* **CSS / SCSS / TailwindCss** 
* **Vite** 
* **React Hooks**
